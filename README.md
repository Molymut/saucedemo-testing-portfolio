# SauceDemo Functional Testing Portfolio

## 📌 Project Overview
This project showcases my manual functional testing work on the SauceDemo web application. The goal was to practice structured test planning, test case design, and execution.

The testing covered the core e-commerce workflow including login, cart management, and checkout functionality.

---

## 🎯 Scope of Testing
- Login functionality (valid and invalid scenarios)
- Cart functionality (add/remove items)
- Checkout functionality (form validation and successful order completion)

---

## 📄 Test Artifacts Included
- Test Plan
- 12 Detailed Test Cases
- Test Execution Summary Report
- Execution Screenshots

Manual Functional Testing
